# Benzineres econòmiques – Osona

Aplicació web per consultar i comparar els preus de les benzineres de la comarca d'Osona, amb dades oficials del Ministeri.

## Funcionalitats

- **Dades oficials**: Preus públics actualitzats a partir de les dades del Ministeri (data i hora de consulta visibles a la web).
- **Targetes de fidelitat**: Introdueix el descompte (en cèntims per litre) d'altres marques per calcular el preu real. La configuració es guarda **només al teu mòbil** (emmagatzematge local).
- **Descompte nocturn**: Algunes estacions apliquen descompte entre les **22:00 i les 08:00**. S'aplica a totes les estacions de la mateixa marca.
- **Geolocalització**: L'aplicació busca la teva ubicació per mostrar les benzineres més properes i econòmiques.

## Tecnologia

- Pàgina estàtica allotjada a **GitHub Pages**.
- Dades obtingudes del Ministeri d'Indústria, Comerç i Turisme.
- Emmagatzematge local al navegador per a les preferències de descompte.

## Ús

1. Obre la web: [https://alexiscd-sudo.github.io/Gasolineres-Osona/](https://alexiscd-sudo.github.io/Gasolineres-Osona/)
2. Permet l'accés a la ubicació per veure les benzineres properes.
3. Opcionalment, indica el descompte de la teva targeta de fidelitat per veure el preu final.
